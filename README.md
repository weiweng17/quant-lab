# 量化实验室（自动运行版）

A 股选股 + 8 策略回测单页网站。数据管道完全使用 Python 标准库，由 GitHub Actions 定时运行、GitHub Pages 托管，零服务器成本。

## 自动运行计划（北京时间）

| 时间 | 内容 |
|---|---|
| 15:30（交易日） | 收盘定稿：选股 → 回测 → 组合体检 → 参数寻优 → 推荐跟踪 → 建站 → 部署 |
| 10:05 / 11:05 / 13:05 / 14:05 / 15:05 | 盘中快照：60分钟K线信号 → 建站 → 部署 |
| 页面打开时 | 报价 30 秒实时轮询（浏览器直连腾讯行情接口，无需服务器） |

数据源：东方财富（主）+ 腾讯行情（自动兜底）。数据与站点文件由机器人自动提交回本仓库。

## 文件结构

- `scan.py` 自上而下选股扫描（大盘 → 板块 → 个股打分）
- `backtest.py` 8 策略回测（含 KDJ 低位金叉）
- `analytics.py` 相关性矩阵 + 月度收益热力图
- `param_scan.py` 策略参数寻优（样本内选参 / 样本外验证）
- `track_picks.py` 历史推荐命中率跟踪（`picks_history.json` 持续累积）
- `fetch_intraday.py` 盘中 60 分钟 K 线快照
- `rescan_tencent.py` 东财断连时的腾讯日 K 兜底
- `build_site.py` 生成单文件网站到 `deploy/index.html`
- `.github/workflows/` 两条定时流水线

## 手动触发

Actions → 选择工作流 → Run workflow（收盘定稿 / 盘中快照 均可手动跑）。

> 注意：GitHub 定时任务高峰期可能延迟 5~15 分钟；仓库 60 天无人工提交会暂停定时任务，随便 push 一个提交即可恢复。
